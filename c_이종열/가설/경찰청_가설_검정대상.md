# 경찰청 데이터 가설 분석 최종 정리

## 분석 목적

경찰청 보이스피싱 통계는 대한민국 전체 보이스피싱의 장기적인 현황과 문제 규모를 설명하는 외부 집계통계 데이터입니다. 이를 활용하여 보이스피싱의 장기적 피해 추세, 사기유형별 피해 차이, 연령대별 피해 분포, 지역별 피해 규모를 확인합니다.

핵심 질문은 다음과 같습니다.

> 대한민국에서 보이스피싱 문제가 실제로 얼마나 크고 어떻게 변화해왔는가?

이를 통해 보이스피싱 문제가 지속적이고 심각한 금융 문제인지 확인하고, AI 기반 송금 안전검증 서비스의 필요성을 설명할 외부 통계 근거를 확보합니다. 이 데이터는 개별 사건 기반 ML 학습용 데이터가 아니며, 분석 결과를 직접 위험점수나 차단 기준으로 사용하지 않습니다.

---

## 현재 분석 상태

- 0단계 데이터 준비 완료
- 1단계 기본 EDA 완료
- P1~P8 분석 완료
- 추가 관계 검정은 진행하지 않음
- 경찰청 데이터 기반 ML은 진행하지 않음
- 이후 작업은 대시보드용 결과 선별 및 시각화

경찰청 데이터는 개별 피해사례가 아닌 집계통계이므로 우체국 데이터처럼 2~4단계의 관계 스크리닝, 다중검정 보정, 피해금액 사후분석으로 확장하지 않습니다.

- 피해금액 단위 확인
- 각 파일의 집계 기준 및 단위 확인
- 데이터 출처 설명과 실제 컬럼 의미가 일치하는지 확인

## P1. 연도별 보이스피싱 발생건수 변화

**상태: 분석 완료**

### 확인 질문
2016~2025년 동안 보이스피싱 발생건수는 어떻게 변화했는가?

### 사용할 변수
- 구분(연도)
- 기관사칭형_발생건수
- 대출사기형_발생건수

### 추가 생성 변수
- 전체_발생건수
  = 기관사칭형_발생건수 + 대출사기형_발생건수

### 확인할 내용
- 연도별 전체 발생건수
- 전년 대비 증감률
- 기관사칭형/대출사기형 비중 변화
- 최근 증가·감소 추세

### 분석 결과
전체 발생건수는 2019년 37,667건으로 가장 많았고, 2023년 18,902건까지 감소한 뒤 2024년 20,839건, 2025년 23,360건으로 최근 2년 연속 증가했습니다. 관찰된 변화의 원인이나 미래 추세를 단정하지 않습니다.

### 서비스 연결
보이스피싱이 일시적인 문제가 아니라 지속적으로 발생하는
금융 피해라는 서비스 필요성 근거로 활용한다.

## P2. 연도별 보이스피싱 피해금액 변화

**상태: 분석 완료**

### 확인 질문
2016~2025년 동안 전체 피해금액은 어떻게 변화했는가?

### 사용할 변수
- 기관사칭형_피해액_억원
- 대출사기형_피해액_억원

### 추가 생성 변수
- 전체_피해액
  = 기관사칭형_피해액 + 대출사기형_피해액

### 확인할 내용
- 연도별 전체 피해액
- 전년 대비 증감률
- 최근 피해액 증가 여부
- 발생건수와 피해액 추세 비교

### 분석 결과
전체 피해금액은 2025년 12,578억원으로 분석기간 중 가장 컸습니다. 2023년 4,472억원에서 2024년 8,545억원, 2025년 12,578억원으로 최근 증가했으며, 발생건수와 피해금액이 항상 같은 방향으로 움직이는 것은 아닙니다.

### 서비스 연결
단순히 사건이 많이 발생하는지를 넘어,
실제 금전적 피해 규모가 얼마나 큰지 제시한다.

## P3. 사기유형별 피해 규모 차이

**상태: 분석 완료**

### 연구 질문
기관사칭형과 대출사기형은 발생건수와 피해금액에서
서로 다른 특성을 보이는가?

### 사용할 변수
- 기관사칭형_발생건수
- 기관사칭형_피해액_억원
- 대출사기형_발생건수
- 대출사기형_피해액_억원

### 추가 확인
- 유형별 연도별 발생 비중
- 유형별 연도별 피해액 비중
- 유형별 건당 평균 피해액

### 중요 확인 변수
건당 피해액 =
피해액 / 발생건수

### 분석 결과
2016~2025년 누적 기준으로 대출사기형이 발생건수와 피해금액 모두 더 컸습니다. 반면 2025년에는 기관사칭형의 발생 비중이 57.03%, 피해 비중이 78.58%였고 건당 피해금액도 더 크게 나타나, 전체 누적 구조와 최근 구조를 구분해 해석해야 합니다.

### 서비스 연결
사기유형별 장기 변화는 통화 분석에서 구조화된 사기유형 결과를 해석하는 배경 정보로 활용합니다. 경찰청 집계 결과를 직접 ML feature나 위험 가중치로 사용하지 않습니다.

## P4. 연령대별 피해자 분포

**상태: 분석 완료**

### 연구 질문
보이스피싱 피해자는 특정 연령대에 집중되어 있는가?

### 사용할 변수
- 연도
- 20대이하
- 30대
- 40대
- 50대
- 60대
- 70대이상

### 확인할 내용
- 전체 기간 연령대별 피해자 수
- 연령대별 피해자 비율
- 연도별 연령 구성 변화
- 최근 몇 년간 증가한 연령대

### 분석 결과
전체 기간 피해자는 50대가 67,314명(25.82%)으로 가장 많았고, 40대 57,510명(22.06%), 20대 이하 54,412명(20.87%) 순이었습니다. 이는 전체 인구 대비 피해율이 아니라 전체 피해자 중 연령대별 구성입니다.

### 주의
현재 데이터는 전체 인구 대비 피해율이 아니다.

따라서
"60대가 보이스피싱에 당할 확률이 높다"
라고 해석하면 안 된다.

정확한 표현:
"전체 피해자 중 특정 연령대의 비중이 높다."

### 서비스 연결
피해자의 연령 구성을 설명하는 외부 통계로 활용합니다. 특정 연령을 위험점수나 직접 차단 기준으로 사용하지 않습니다.

**상태: 분석 완료**

보이스피싱 피해자의 연령 구성은 시간에 따라 변화했는가?

### 확인할 내용

### 서비스 연결
보이스피싱이 특정 고정 타깃만의 문제가 아니라
시간에 따라 피해집단이 달라지는지 확인한다.

지역별 보이스피싱 발생규모에는 차이가 있는가?

### 사용할 변수
- 시도청
- 2016년 ~ 2025년

### 확인할 내용
- 지역별 전체 발생건수
- 연도별 지역 발생건수
- 전체 피해에서 각 지역이 차지하는 비중
- 최근 증가폭이 큰 지역

2016~2025년 누적 발생건수는 서울이 74,223건으로 가장 많았고 경기남부가 47,887건으로 뒤를 이었습니다. 인구가 보정되지 않은 총 발생규모이므로 지역별 위험률로 해석하지 않습니다.

### 주의
지역별 인구 규모가 다르므로
단순 발생건수만으로 특정 지역의
'보이스피싱 위험확률'이 높다고 해석하면 안 된다.

### 서비스 연결
보이스피싱이 특정 지역에만 국한되지 않고
전국적인 금융 문제인지 설명하는 보조 근거로 활용한다.

- 시도청
- 2023년
- 2024년
- 2025년

### 확인할 내용

### 주의
지역별 인구와 사건 수가 다르기 때문에
총 피해금액만으로 피해 심각도를 비교해서는 안 된다.

## P8. 지역별 건당 피해금액 비교

**상태: 분석 완료**

### 연구 질문
지역에 따라 보이스피싱 1건당 피해금액에 차이가 있는가?

### 사용할 데이터
- 시도경찰청별 피해 현황
- 시도청별 피해금액 현황

### 공통 기간
- 2023년
- 2024년
- 2025년

### 계산
지역별 건당 피해금액 =
지역별 피해금액 / 지역별 발생건수

2023~2025년 전체 건당 피해금액은 연도별 건당 피해금액의 단순 평균이 아니라 다음과 같이 계산합니다.

`2023~2025년 총 피해금액 / 2023~2025년 총 발생건수`

### 확인할 내용
- 발생건수는 적지만 건당 피해가 큰 지역 존재 여부
- 단순 총 피해액 순위와 건당 피해액 순위 차이

### 분석 결과
2023~2025년 합산 기준 건당 피해금액은 서울이 4,767.08만원으로 가장 컸고, 광주 4,407.18만원, 세종 4,236.45만원 순이었습니다.

### 주의
- 이는 지역 인구를 보정한 위험률이 아닙니다.
- 지역 자체가 피해규모 차이의 원인임을 의미하지 않습니다.
- 지역별 피해금액 원본 컬럼에는 단위가 직접 명시되어 있지 않습니다.
- 전체 피해액 자료와 연도별 합계의 일관성을 근거로 분석상 억원 단위로 해석했습니다.

### 서비스 연결
서비스 필요성을 설명하는 보조 분석으로 활용하고,
AI 위험점수의 핵심 feature로 직접 사용하지 않는다.

## 기존 전체 분석 로드맵과의 관계

기존 로드맵 중 경찰청 데이터는 0단계 데이터 준비와 1단계 기본 EDA를 완료했습니다. 집계통계라는 특성상 여기서 분석을 종료하며, 복합 관계 심층분석·군집분석·경찰청 데이터 기반 별도 ML은 진행하지 않습니다.

정상통화와 보이스피싱 비교, 심리압박, 유사도, ML 위험 탐지는 경찰청 데이터가 아닌 별도의 통화·전사 데이터 분석 영역에서 진행합니다.

## 이후 단계

현재 데이터 분석은 대시보드에 활용할 후보 결과를 확보한 상태이며, 이후 단계에서는 새로운 분석을 추가하기보다 기존 결과 중 전달 가치가 높은 그래프·표·인사이트를 선별합니다. 대시보드의 O/△/X 최종 판정은 다음 단계에서 별도로 진행합니다.
