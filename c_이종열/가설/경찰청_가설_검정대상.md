# 경찰청 데이터 가설 검정 대상

## 분석 목적

경찰청 보이스피싱 통계를 활용하여
보이스피싱의 장기적 피해 추세, 사기유형별 피해 차이,
연령대별 피해 분포, 지역별 피해 규모를 확인한다.

이를 통해 보이스피싱 문제가 지속적이고 심각한 금융 문제인지 확인하고,
AI 기반 송금 안전검증 서비스가 필요한 근거를 확보한다.

---

## 공통 데이터 확인사항

- CSV 인코딩 확인
  - 현재 원본은 cp949로 정상 로드됨
- 컬럼명 앞뒤 공백 제거
- 문자열 데이터 앞뒤 공백 제거
- 숫자형 컬럼 dtype 확인
- 결측치 확인
- 중복 행 확인
- 연도 컬럼 정수형 변환 필요 여부 확인
- 피해금액 단위 확인
- 각 파일의 집계 기준 및 단위 확인
- 데이터 출처 설명과 실제 컬럼 의미가 일치하는지 확인

## P1. 연도별 보이스피싱 발생건수 변화

### 확인 질문
2016~2025년 동안 보이스피싱 발생건수는 어떻게 변화했는가?

### 사용할 변수
- 구분(연도)
- 기관사칭형_발생건수
- 대출사기형_발생건수

### 추가 생성 변수
- 전체_발생건수
  = 기관사칭형_발생건수 + 대출사기형_발생건수

### 확인할 내용
- 연도별 전체 발생건수
- 전년 대비 증감률
- 기관사칭형/대출사기형 비중 변화
- 최근 증가·감소 추세

### 서비스 연결
보이스피싱이 일시적인 문제가 아니라 지속적으로 발생하는
금융 피해라는 서비스 필요성 근거로 활용한다.

---

## P2. 연도별 보이스피싱 피해금액 변화

### 확인 질문
2016~2025년 동안 전체 피해금액은 어떻게 변화했는가?

### 사용할 변수
- 기관사칭형_피해액_억원
- 대출사기형_피해액_억원

### 추가 생성 변수
- 전체_피해액
  = 기관사칭형_피해액 + 대출사기형_피해액

### 확인할 내용
- 연도별 전체 피해액
- 전년 대비 증감률
- 최근 피해액 증가 여부
- 발생건수와 피해액 추세 비교

### 서비스 연결
단순히 사건이 많이 발생하는지를 넘어,
실제 금전적 피해 규모가 얼마나 큰지 제시한다.

## P3. 사기유형별 피해 규모 차이

### 연구 질문
기관사칭형과 대출사기형은 발생건수와 피해금액에서
서로 다른 특성을 보이는가?

### 사용할 변수
- 기관사칭형_발생건수
- 기관사칭형_피해액_억원
- 대출사기형_발생건수
- 대출사기형_피해액_억원

### 추가 확인
- 유형별 연도별 발생 비중
- 유형별 연도별 피해액 비중
- 유형별 건당 평균 피해액

### 중요 확인 변수
건당 피해액 =
피해액 / 발생건수

### 서비스 연결
사기유형에 따라 피해 심각도가 다르다면,
통화에서 탐지된 사기유형을 AI 위험도 판단에
활용할 근거가 된다.

## P4. 연령대별 피해자 분포

### 연구 질문
보이스피싱 피해자는 특정 연령대에 집중되어 있는가?

### 사용할 변수
- 연도
- 20대이하
- 30대
- 40대
- 50대
- 60대
- 70대이상

### 확인할 내용
- 전체 기간 연령대별 피해자 수
- 연령대별 피해자 비율
- 연도별 연령 구성 변화
- 최근 몇 년간 증가한 연령대

### 주의
현재 데이터는 전체 인구 대비 피해율이 아니다.

따라서
"60대가 보이스피싱에 당할 확률이 높다"
라고 해석하면 안 된다.

정확한 표현:
"전체 피해자 중 특정 연령대의 비중이 높다."

### 서비스 연결
특정 연령만을 무조건 차단하는 것이 아니라,
연령을 다른 위험신호와 결합할 보조 변수로 활용할 수 있는지 확인한다.

## P5. 연령대별 피해 구조의 연도 변화

### 연구 질문
보이스피싱 피해자의 연령 구성은 시간에 따라 변화했는가?

### 확인할 내용
- 각 연도의 연령대별 피해자 비중
- 2016년과 2025년 구성 비교
- 연령대별 증감 추세
- 최근 피해 증가가 두드러지는 집단

### 서비스 연결
보이스피싱이 특정 고정 타깃만의 문제가 아니라
시간에 따라 피해집단이 달라지는지 확인한다.

## P6. 지역별 보이스피싱 발생규모 차이

### 연구 질문
지역별 보이스피싱 발생규모에는 차이가 있는가?

### 사용할 변수
- 시도청
- 2016년 ~ 2025년

### 확인할 내용
- 지역별 전체 발생건수
- 연도별 지역 발생건수
- 전체 피해에서 각 지역이 차지하는 비중
- 최근 증가폭이 큰 지역

### 주의
지역별 인구 규모가 다르므로
단순 발생건수만으로 특정 지역의
'보이스피싱 위험확률'이 높다고 해석하면 안 된다.

### 서비스 연결
보이스피싱이 특정 지역에만 국한되지 않고
전국적인 금융 문제인지 설명하는 보조 근거로 활용한다.

지역별 보이스피싱 피해금액 규모에는 차이가 있는가?

### 확인할 내용

## P8. 지역별 건당 피해금액 비교

### 연구 질문
지역에 따라 보이스피싱 1건당 피해금액에 차이가 있는가?

### 사용할 데이터
- 시도경찰청별 피해 현황
- 시도청별 피해금액 현황

### 공통 기간
- 2023년
- 2024년
- 2025년

### 계산
지역별 건당 피해금액 =
지역별 피해금액 / 지역별 발생건수

### 확인할 내용
- 발생건수는 적지만 건당 피해가 큰 지역 존재 여부
- 단순 총 피해액 순위와 건당 피해액 순위 차이

### 주의
이는 지역 자체가 피해의 원인임을 증명하는 분석이 아니다.

### 서비스 연결
서비스 필요성을 설명하는 보조 분석으로 활용하고,
AI 위험점수의 핵심 feature로 직접 사용하지 않는다.
