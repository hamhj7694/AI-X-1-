# 우체국 금융사기 피해사례 가설 분석 최종 정리

## 분석 목적

개별 보이스피싱 피해 사례를 이용하여
피해자의 특성, 사기유형, 사칭기관과
실제 피해금액 간 관계를 확인합니다.

우체국 데이터의 역할은 실제 보이스피싱 피해사례에서 피해자 특성, 사기유형, 사칭기관과 피해금액 간 관계를 이해하는 것입니다. 분석 결과는 실제 피해사례의 특성을 이해하고, 통화 분석 결과와 LLM 구조화 결과를 설명하거나 RAG 사례 비교를 보조하는 참고 근거로 활용합니다. 직접적인 AI 위험점수 feature나 자동 차단 기준을 만드는 데이터로 사용하지 않습니다.

---

## 현재 분석 상태

- 0단계 데이터 준비 완료
- 1단계 기본 EDA 완료
- 2단계 전체 관계 스크리닝 완료
- 3단계 Benjamini-Hochberg 다중검정 보정 완료
- 4단계 피해금액 사후분석 완료
- 현재 범위에서 통계분석 종료
- 우체국 데이터 기반 별도 ML은 진행하지 않음
- 이후 대시보드용 결과 선별 및 시각화 진행

---

# 핵심 검정대상

## U1. 연령대 ↔ 피해금액

**상태: 분석 완료**

연령대에 따라 보이스피싱 피해금액에 차이가 있는가?

- 독립변수: 연령대
- 종속변수: 피해액
- 목적: 연령이 피해 심각도와 관련되는지 확인

연령대별 피해금액 분포 차이는 BH 보정 후에도 확인되었고 효과크기도 크게 나타났습니다. 다만 연령이 피해금액 차이의 원인이라는 의미는 아니며, 연령 단독 차단 기준으로 사용하지 않습니다.


## U2. 성별 ↔ 피해금액

**상태: 분석 완료 — 뚜렷한 차이에 대한 통계적 근거 없음**

성별에 따라 피해금액에 차이가 있는가?

- 독립변수: 성별
- 종속변수: 피해액
- 목적: 성별에 따라 실제 피해금액 분포에 차이가 나타나는지 확인

현재 표본에서는 BH 보정 후 성별에 따른 피해금액 차이의 통계적 근거가 약했고 효과크기도 매우 작았습니다. 이는 분석 실패가 아니라 차이를 뒷받침할 근거가 확인되지 않았다는 완료 결과입니다.


## U3. 연령대 ↔ 고액피해 여부

**상태: 현재 분석 미진행**

연령대와 고액피해 여부는 관련이 있는가?

- 변수: 연령대, 고액피해 여부
- 목적: 특정 연령대에서 고액피해 비율이 높은지 확인

연령대 ↔ 실제 피해금액 분석을 우선하며 고액피해 기준을 별도로 설정하지 않았습니다.


## U4. 사기유형 ↔ 피해금액

**상태: 분석 완료**

사기유형에 따라 피해금액에 차이가 있는가?

- 독립변수: 사기유형
- 종속변수: 피해액
- 중요도: 높음

사기유형별 피해금액 분포 차이는 BH 보정 후에도 확인되었고 효과크기도 크게 나타났습니다. 다만 1~2건인 작은 표본 범주가 포함되어 있어 확정적인 유형 순위나 인과관계로 해석하지 않습니다.


## U5. 사칭기관 ↔ 피해금액

**상태: 분석 완료**

사칭기관에 따라 피해금액에 차이가 있는가?

- 독립변수: 사칭기관
- 종속변수: 피해액
- 중요도: 높음

사칭기관별 피해금액 분포 차이는 BH 보정 후에도 확인되었고 효과크기도 크게 나타났습니다. 일부 기관은 표본이 2~4건으로 작으므로 확정적인 순위로 해석하지 않습니다.


## U6. 사기유형 ↔ 사칭기관

**상태: 분석 완료**

사기유형과 사칭기관은 서로 관련되어 있는가?

- 변수: 사기유형, 사칭기관
- 목적: 반복되는 보이스피싱 시나리오 조합 확인
- 서비스 연결: LLM 구조화 + RAG 사례 비교

통계적 관계 후보는 확인되었으나 작은 표본 범주와 카이제곱 검정의 기대빈도 조건 문제로 해석에 주의가 필요합니다. 이 결과는 인과관계나 자동 차단 규칙을 의미하지 않습니다.


## U7. 사기유형 ↔ 고액피해 여부

**상태: 현재 분석 미진행**

사기유형에 따라 고액피해 발생 비율이 다른가?

- 변수: 사기유형, 고액피해 여부
- 사유: 사기유형 ↔ 실제 피해금액 분석을 우선하며 고액피해 여부를 별도 핵심 Target으로 사용하지 않음


## U8. 사칭기관 ↔ 고액피해 여부

**상태: 현재 분석 미진행**

사칭기관에 따라 고액피해 발생 비율이 다른가?

- 변수: 사칭기관, 고액피해 여부
- 사유: 사칭기관 ↔ 실제 피해금액 분석을 우선하며 고액피해 여부를 별도 핵심 Target으로 사용하지 않음

## 추가 확인사항

- 피해금액 평균뿐 아니라 중앙값 확인
- 피해금액 이상치 확인
- 사기유형별 표본 수 확인
- 사칭기관별 표본 수 확인
- 표본이 지나치게 적은 범주는 통합할지 검토
- 고액피해 기준이 타당한지 확인
- 고액피해 기준 변경에 따른 결과 변화 확인
- 피해금액 분포가 정규분포인지 확인
- 연령대별 표본 불균형 확인
- 성별 표본 불균형 확인
- 투자사기 데이터는 현재 서비스 범위에서 제외
- 전화 보이스피싱 사례만 분석할 경우 표본 수 재확인

위 확인사항은 0~4단계 분석에서 검토했으며, 현재 범위에서 추가 통계검정은 진행하지 않습니다.

## 고액피해 기준 최종 판단

고액피해 기준으로 다음을 검토했습니다.

- Q3
- 상위 25%
- 고정금액
- 평균 + 1표준편차

하지만 현재 프로젝트에서는 별도 `고액피해 여부` 변수를 핵심 분석 Target으로 만들지 않습니다.

1. 기준 선택에 따라 분류가 달라질 수 있습니다.
2. 피해금액을 이진화하면 실제 피해 규모 정보가 손실됩니다.
3. 현재 서비스는 고액피해자를 예측하는 서비스가 아닙니다.
4. 이미 실제 피해금액을 사용한 관계 분석을 수행했습니다.

따라서 **실제 피해금액 자체를 핵심 분석 변수로 유지합니다.** 대시보드에서 피해 심각성을 설명하기 위한 보조 KPI로 특정 금액 이상 사례 비중을 보여주는 것은 별도로 검토할 수 있습니다.

## 추가 탐색 관계

피해자 특성과 사기수법 사이에 반복되는 조합이 있는지 탐색하기 위한 보조 분석으로 다음 관계를 확인했습니다.

- 연령대 ↔ 사기유형
- 연령대 ↔ 사칭기관
- 성별 ↔ 사기유형
- 성별 ↔ 사칭기관

이 관계들은 메인 가설이 아니며, 작은 표본과 카이제곱 검정의 기대빈도 문제가 있습니다. 대시보드에서 반드시 사용할 결과가 아니고, 통화 분석 결과를 해석하는 참고자료로 활용할 수 있습니다.

## 서비스 연결과 해석 범위

우체국 분석 결과는 다음 범위에서 활용합니다.

- 실제 피해사례 특성 이해
- 통화 분석 결과 해석 보조
- LLM 구조화 결과 설명
- RAG 사례 비교 참고

연령 단독 차단, 사기유형별 자동 차단 기준 확정, 사칭기관별 위험 가중치 직접 확정, 우체국 데이터만을 이용한 ML 위험모델 제작에는 사용하지 않습니다.

## 기존 전체 분석 로드맵과의 관계

기존 로드맵 중 우체국 데이터는 0단계 데이터 준비부터 4단계 피해금액 사후분석까지 완료했으며 현재 범위에서 종료합니다. 복합 관계 심층분석, 군집분석, 우체국 데이터 기반 별도 ML은 생략합니다.

정상통화와 보이스피싱 비교, 심리압박, 유사도, ML 위험 탐지는 우체국·경찰청 데이터가 아닌 별도의 통화·전사 데이터 분석 영역에서 진행합니다.

## 이후 단계

현재 데이터 분석은 대시보드에 활용할 후보 결과를 확보한 상태이며, 이후 단계에서는 새로운 분석을 추가하기보다 기존 결과 중 전달 가치가 높은 그래프·표·인사이트를 선별합니다. 대시보드의 O/△/X 최종 판정은 다음 단계에서 별도로 진행합니다.
