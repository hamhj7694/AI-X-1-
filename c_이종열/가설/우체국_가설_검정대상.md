# 우체국 금융사기 피해사례 가설 검정 대상

## 분석 목적

개별 보이스피싱 피해 사례를 이용하여
피해자의 특성, 사기유형, 사칭기관과
피해금액 및 고액피해 간 관계를 확인한다.

이를 통해 AI 위험도 산정 및
고위험 송금 다중검증 활성화 조건의
후보 변수를 탐색한다.

---

# 핵심 검정대상

## U1. 연령대 ↔ 피해금액

연령대에 따라 보이스피싱 피해금액에 차이가 있는가?

- 독립변수: 연령대
- 종속변수: 피해액
- 목적: 연령이 피해 심각도와 관련되는지 확인


## U2. 성별 ↔ 피해금액

성별에 따라 피해금액에 차이가 있는가?

- 독립변수: 성별
- 종속변수: 피해액
- 목적: 성별을 위험 판단 변수로 사용할 근거가 있는지 확인


## U3. 연령대 ↔ 고액피해 여부

연령대와 고액피해 여부는 관련이 있는가?

- 변수: 연령대, 고액피해 여부
- 목적: 특정 연령대에서 고액피해 비율이 높은지 확인


## U4. 사기유형 ↔ 피해금액

사기유형에 따라 피해금액에 차이가 있는가?

- 독립변수: 사기유형
- 종속변수: 피해액
- 중요도: 높음


## U5. 사칭기관 ↔ 피해금액

사칭기관에 따라 피해금액에 차이가 있는가?

- 독립변수: 사칭기관
- 종속변수: 피해액
- 중요도: 높음


## U6. 사기유형 ↔ 사칭기관

사기유형과 사칭기관은 서로 관련되어 있는가?

- 변수: 사기유형, 사칭기관
- 목적: 반복되는 보이스피싱 시나리오 조합 확인
- 서비스 연결: LLM 구조화 + RAG 사례 비교


## U7. 사기유형 ↔ 고액피해 여부

사기유형에 따라 고액피해 발생 비율이 다른가?

- 변수: 사기유형, 고액피해 여부
- 중요도: 높음
- 서비스 연결: 위험도 가중치 후보


## U8. 사칭기관 ↔ 고액피해 여부

사칭기관에 따라 고액피해 발생 비율이 다른가?

- 변수: 사칭기관, 고액피해 여부
- 중요도: 높음
- 서비스 연결: 독립검증 활성화 조건 후보

## 추가 확인사항

- 피해금액 평균뿐 아니라 중앙값 확인
- 피해금액 이상치 확인
- 사기유형별 표본 수 확인
- 사칭기관별 표본 수 확인
- 표본이 지나치게 적은 범주는 통합할지 검토
- 고액피해 기준이 타당한지 확인
- 고액피해 기준 변경에 따른 결과 변화 확인
- 피해금액 분포가 정규분포인지 확인
- 연령대별 표본 불균형 확인
- 성별 표본 불균형 확인
- 투자사기 데이터는 현재 서비스 범위에서 제외
- 전화 보이스피싱 사례만 분석할 경우 표본 수 재확인
