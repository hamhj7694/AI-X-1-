# Colab GPU 실행 가이드

## 준비 파일

- `보이스피싱_Colab_GPU_분석.ipynb`
- `transcribe_cases.py`

## Google Drive 구조

Google Drive에 다음 구조로 원본을 업로드한다.

```text
내 드라이브/
  보이스피싱_분석/
    원본 영상 및 음원/
      바로 이 목소리/
      그놈 목소리 - 대출사기형/
      그놈 목소리 - 수사기관형/
```

원본 전체는 약 5.7GB이므로 브라우저 업로드가 불안정하면 Google Drive 데스크톱 앱을
사용한다. 음성 파일이 Google Drive와 Colab에 저장·처리되는 것에 대한 권한과
개인정보 처리 기준을 먼저 확인한다.

## 실행 순서

1. Colab에서 `보이스피싱_Colab_GPU_분석.ipynb`를 연다.
2. 런타임 유형을 GPU로 변경한다.
3. Colab Secrets에 `HF_TOKEN`을 등록하고 노트북 접근을 허용한다.
4. 위에서부터 셀을 순서대로 실행한다.
5. 스크립트 업로드 셀에서 `transcribe_cases.py`를 선택한다.
6. 1건 시험 결과가 정상인지 확인한 뒤 전체 실행 셀을 실행한다.
7. 세션이 끊기면 다시 연결하고 전체 실행 셀까지 순서대로 실행한다. 완료된 파일은 건너뛴다.
8. 마지막 완료 검증 셀에서 입력 수와 완료 수가 일치하는지 확인한다.

## 결과 위치

결과는 Google Drive의 `내 드라이브/보이스피싱_분석/분석 결과`에 저장된다.

- `cases.json`: 사건·화자·역할·발화 기준 데이터
- `turns.csv`: 신뢰도 기준을 통과한 ML 학습 후보
- `검수필요.csv`: 역할 또는 사건 경계 검수가 필요한 발화
- `review.txt`: 사람이 읽고 듣기 위한 스크립트

OpenAI/GPT API는 사용하지 않으며 관련 API 키도 필요하지 않다.
