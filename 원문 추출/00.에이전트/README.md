# 보이스피싱 데이터 프로젝트 에이전트

## 목적

데이터 구축, 머신러닝 보조 라벨링, 모델 학습·평가를 서로 다른 관점에서 검토하기 위한 역할 정의이다.
각 에이전트는 결론만 내리지 않고 판단 근거, 위험, 확인 방법을 함께 제시한다.

## 운영 순서

1. `라우터_오케스트레이션_에이전트`가 요청을 작업 단위로 분해한다.
2. 데이터 구조는 `데이터분석가_에이전트`, 모델은 `머신러닝_전문가_에이전트`가 검토한다.
3. 구현은 `개발자_에이전트`, 학습용 설명은 `교육강사_에이전트`가 담당한다.
4. `검증가_에이전트`가 데이터 누출, 평가 오류, 재현성을 독립 점검한다.
5. 라우터가 의견 충돌과 미확인 사항을 기록하고 최종안을 확정한다.
6. `문서작성_에이전트`가 확정된 결과를 사용자 양식과 보고서 목적에 맞게 작성한다.

## 공통 원칙

- 실제 피해 여부가 없는 자료로 피해 발생을 예측했다고 표현하지 않는다.
- 규칙·모델 자동 라벨은 `SILVER`, 사람이 확인한 라벨은 `GOLD`로 구분한다.
- 규칙이 만든 라벨로 학습하고 같은 규칙 라벨로만 평가한 결과를 실제 정확도로 해석하지 않는다.
- 같은 원본 파일의 사건·발화·구간이 학습과 평가에 나뉘지 않도록 `group_id`로 분리한다.
- 원본 텍스트와 자동 전처리 텍스트를 모두 보존한다.
- 코드 실행 결과와 검증 보고서를 저장하여 재현 가능하게 만든다.
- 문서 작성자는 확정되지 않은 추정치를 사실처럼 보완하지 않고 `확인 필요`로 표시한다.

## 문서 작성 인계 순서

```text
분석가·ML 전문가의 결과
→ 검증가의 승인 및 제한사항
→ 라우터의 최종 결정
→ 문서작성 에이전트의 양식 적용
→ 검증가의 수치·표현 최종 확인
```
