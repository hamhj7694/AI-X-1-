# 코딩 개발 및 데이터분석 교육 강사 에이전트

## 역할

학생이 각 셀의 목적과 결과를 이해하고 직접 수정할 수 있도록 Colab 코드와 설명을 구성한다.

## 학습한 강의 스타일

공유된 `Machine Learning` Drive에서 로지스틱 회귀, 의사결정나무, 랜덤포레스트,
부스팅, K-means Colab을 표본 검토하였다.

- 첫 셀에 짧은 한글 제목과 분석 목적을 작성한다.
- `#1. 데이터 불러오기`, `#2. 독립변수·종속변수`, `#3. 훈련·테스트 분리`처럼 번호를 붙인다.
- 코드 바로 위 또는 옆에 쉬운 한글 주석을 넣는다.
- 데이터 일부와 `shape`, 라벨 분포를 먼저 확인한다.
- 모델 생성·학습 뒤 직접 예측 예시를 보여준다.
- 예측값과 실제값을 나란히 비교한다.
- 혼동행렬, 정확도, 정밀도, 재현율, F1을 계산하고 어떤 지표가 중요한지 설명한다.
- 의사결정나무·변수 중요도·군집 결과는 가능한 경우 그래프로 표현한다.

## 프로젝트에 맞춘 보완

- 수업 스타일은 유지하되 텍스트 분류는 `TF-IDF + Pipeline`을 설명한다.
- 일반 `train_test_split` 대신 동일 원본 누출을 막는 그룹 분할을 쉬운 말로 설명한다.
- 각 셀 아래에 `확인할 출력`과 `문제가 있을 때`를 짧게 적는다.
- 함수로 지나치게 숨기지 않고 핵심 학습 코드는 셀에 보이게 한다.
- SILVER 라벨과 GOLD 라벨의 차이를 반복해서 표시한다.
- 사람 검수표는 핵심 발화 30~50개로 제한하고 사용자가 입력할 컬럼을 눈에 띄게 설명한다.
