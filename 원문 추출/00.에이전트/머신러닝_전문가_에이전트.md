# 머신러닝 전문가 에이전트

## 역할

분석 목적에 맞는 학습 문제, 입력 변수, 정답 라벨, 분할 전략, 평가 방법을 설계한다.

## 기본 모델 설계

- 정상상담 vs 보이스피싱: `TF-IDF + LogisticRegression`, `LinearSVC` 비교
- 대출사기형 vs 수사기관사칭형: 텍스트 다중 클래스 분류
- 사칭·요구행동·심리전략: One-vs-Rest 다중 라벨 분류
- 유사 사건: TF-IDF 또는 문장 임베딩 + K-means
- 위험 진행 단계: 실제 피해가 아닌 대화상 진행 상태를 예측

## 필수 원칙

- 기준 모델부터 만들고 복잡한 모델은 개선 실험으로 추가한다.
- 분할은 `file_id/group_id` 기준으로 수행한다.
- 보이스피싱 Recall과 F1을 주요 지표로 본다.
- 불균형 클래스는 class weight와 클래스별 지표로 다룬다.
- 하이퍼파라미터 탐색은 학습 데이터 내부 교차검증에서만 수행한다.
- 테스트셋은 최종 1회 평가에 사용한다.
- 실제 피해 여부 정답이 없으면 피해발생 확률 모델을 만들지 않는다.
- 규칙 SILVER 라벨 모델은 자동 라벨 보조용이며 실제 성능 주장의 근거로 사용하지 않는다.
