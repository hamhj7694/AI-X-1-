# 01 데이터셋 구축 v2 실행 가이드

## 목적

보이스피싱 전사자료, 정상 금융상담, 우체국 피해사례를 이용해 17개 데이터테이블을 생성하고 기본 무결성을 검사한다.
사람 표본 검수와 머신러닝 학습은 수행하지 않는다.

## Google Drive 배치

```text
보이스피싱_분석/
├─ 분석 결과/
│  ├─ 그놈 목소리 - 대출사기형/
│  ├─ 그놈 목소리 - 수사기관형/
│  ├─ 바로 이 목소리/
│  ├─ 00.금융분야 고객상담 데이터/
│  └─ 데이터셋/
│     ├─ df_postal.csv
│     └─ 01_dataset_building/
│        ├─ 01_dataset_building_v2.ipynb
│        └─ build_voicephishing_datasets_v2.py
└─ 구축 데이터셋_v3/                 # 금액 방향·용도 확장 버전
```

정상상담 폴더가 `보이스피싱_분석` 바로 아래에 있어도 자동으로 찾는다.

## 실행 방법

1. `01_dataset_building_v2.ipynb`를 Google Colab으로 연다.
2. 셀을 위에서부터 순서대로 실행한다.
3. Google Drive 접근을 허용한다.
4. 입력 확인 셀에서 다음 내용을 확인한다.

```text
보이스피싱 cases.json: 402개
정상상담 전체 ZIP: 12개
실제 처리할 TL/VL ZIP: 6개
```

5. 마지막에 다음 세 문구가 출력되는지 확인한다.

```text
생성 테이블: 17개
기본 무결성 검사 통과
CSV 17개 + Parquet 17개 저장 완료
```

현재 노트북은 `SKIP_EXISTING = True`로 설정되어 있다. 같은 이름의 CSV 또는 Parquet가 이미 있으면 해당 파일을 덮어쓰지 않고 `[건너뜀]`으로 표시한다.
금액 방향·용도 컬럼을 새로 반영한 결과는 기존 `구축 데이터셋_v2`를 보존하고 `구축 데이터셋_v3`에 저장한다.

## 생성 결과

- 표준 데이터테이블: 8개
- 머신러닝 준비 테이블: 4개
- 대시보드 테이블: 5개
- CSV: 17개
- Parquet: 17개
- manifest와 validation report: 2개

`dashboard_case_summary`는 Python·ML 작업을 위한 영문 컬럼을 유지한다.
`보이스피싱_사건요약_한글`은 동일한 대시보드 파생변수와 금액·사칭 상세정보를 한글 컬럼으로 제공하므로, 사람이 확인하거나 대시보드를 만들 때 사용한다.

`vp_amount_events`에는 금액 자체 외에 `amount_direction`(제안·요구·피해자 동의·이체 주장), `amount_purpose`(수수료·보증금·환급 등), 근거문장과 규칙 신뢰도가 포함된다. 이 값은 규칙 기반 `SILVER` 라벨이다.

## 1단계와 2단계의 차이

- 1단계: 파일 생성, ID 중복·누락, 테이블 연결 오류 확인
- 2단계: 역할·사칭·행동·심리전략·금액 상태의 의미가 맞는지 표본 검수
