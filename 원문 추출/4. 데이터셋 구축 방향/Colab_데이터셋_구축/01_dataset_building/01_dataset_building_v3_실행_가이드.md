# 1단계 v3 실행 가이드

## Summary

기존 17개 테이블 구조를 유지하면서 사칭기관을 사건 단위로 다시 판정하여 `구축 데이터셋_v4`를 생성합니다. 기존 `구축 데이터셋_v3`는 덮어쓰지 않습니다.

## 필요한 파일

```text
01_dataset_building_v3.ipynb
build_voicephishing_datasets_v3.py
```

스크립트는 Google Drive의 다음 위치에 둡니다.

```text
내 드라이브/보이스피싱_분석/분석 결과/데이터셋/01_dataset_building/
```

노트북 위치는 실행에 영향을 주지 않습니다.

## 실행 방법

1. 두 파일을 Drive에 업로드합니다.
2. `01_dataset_building_v3.ipynb`를 Colab으로 엽니다.
3. **런타임 → 모두 실행**을 누릅니다.
4. 마지막 셀에서 17개 테이블, 무결성 통과, 사건 단위 사칭 컬럼 검증 완료를 확인합니다.

## 사건 단위 사칭 판정

- `HIGH`: 범인의 명시적 자기소개가 명확함
- `MEDIUM`: 범인 발화에서 직책이 나타나거나 동일 기관이 반복됨
- `UNKNOWN`: 단순 언급, 후보 충돌 또는 근거 부족
- 접근기관·주요기관·보조기관·전체 언급기관·전환순서를 분리 저장
- 불확실한 사건은 주요 기관을 강제 선택하지 않고 검수 대상으로 보존

## 2·3단계 호환성

기존 17개 테이블명과 필수 컬럼을 유지하므로 분석 코드는 변경하지 않습니다. 새 입력을 사용하려면 기존 2·3단계 설정 셀에서 경로 한 줄만 바꿉니다.

```python
DATASET_ROOT = PROJECT_ROOT / '구축 데이터셋_v4'
```

기존 경로를 유지하면 과거 v3를 읽게 되므로 새 사건 단위 판정 결과가 반영되지 않습니다.

## 주의

사칭 결과는 사건 전체 후보를 사용하는 개선된 `SILVER` 라벨입니다. `HIGH`도 사람 확정 `GOLD`와 동일하지 않으며, 보고서에는 자동 추출 결과임을 명시합니다.
