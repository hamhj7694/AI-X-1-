# 3단계 통합 v5 실행 가이드

## Summary

`03_integrated_analysis_v5.ipynb` 하나를 Colab에서 위에서부터 순서대로 실행하면 기존 03-1·업데이트된 03-2 EDA v2·03-3 분석이 한 번에 진행됩니다.

## 실행 전 확인

- Google Drive에 `보이스피싱_분석/구축 데이터셋_v4`가 있어야 합니다.
- `01_standard_tables`, `02_ml_tables`, `03_dashboard_tables` 폴더가 있어야 합니다.
- 기존 03단계 노트북은 실행하지 않아도 됩니다.

## 실행 순서

1. `03_integrated_analysis_v5.ipynb`를 Google Drive에 업로드합니다.
2. Colab으로 열고 `런타임 → 모두 실행`을 선택합니다.
3. Google Drive 접근을 허용합니다.
4. 마지막 셀의 `3단계 통합 v5 정상 완료` 메시지를 확인합니다.

## 분석 흐름

```text
구축 데이터셋_v4 불러오기
→ 데이터 품질 및 EDA
→ 의미 단어·2-gram·의미 범주 분석
→ 사건 단위 주요 사칭기관·판정률 확인
→ 행동·심리 특징 지도·비지도 분석
→ 정상상담 vs 보이스피싱 모델 비교
→ 사기유형·구간탐지·유사사건 군집분석
→ 결과·모델·보고서 저장
```

## 저장 위치

결과는 기존 파일을 덮어쓰지 않고 다음 폴더에 저장됩니다.

```text
내 드라이브/보이스피싱_분석/머신러닝_분석결과_v5_통합
├─ 01_EDA
├─ 02_해석형특징분석
├─ 03_텍스트ML
├─ 통합_산출물_요약.csv
└─ 통합_실행기록_v5.json
```

## 주의

- 사칭기관은 사건 단위 `HIGH`, `MEDIUM`, `UNKNOWN` 판정률과 함께 해석합니다.
- 정상상담과 보이스피싱의 출처·편집 방식이 달라 높은 모델 점수에 데이터 출처 편향이 포함될 수 있습니다.
- 실제 피해 여부 라벨이 없으므로 결과를 피해 발생 확률로 해석하지 않습니다.
