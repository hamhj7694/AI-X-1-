# V5-3 보이스피싱 유사도 탐지 실행 가이드

## Summary

기존 보이스피싱 사례의 문구·행동·심리 특징을 수치화한 기준 라이브러리를 만들고, 신규 텍스트와의 보이스피싱 유사도를 계산합니다. 대출사기형·수사기관사칭형 분류 모델은 만들지 않습니다.

## 실행 방법

1. `03_similarity_detection_v5_3.ipynb`를 Google Drive에 업로드합니다.
2. `보이스피싱_분석/구축 데이터셋_v4`가 있는지 확인합니다.
3. Colab에서 `런타임 → 모두 실행`을 선택합니다.
4. 마지막 셀에서 `V5-3 유사도 탐지 정상 완료`를 확인합니다.

## 분석 흐름

```text
보이스피싱 사례만 불러오기
→ 문구·행동·심리 특징 수치화
→ TF-IDF 문구 벡터와 전술 특징 벡터 생성
→ 유사 사건 기준 라이브러리와 전술 군집 구축
→ 원본 파일 단위 홀드아웃 보이스피싱 포착률 확인
→ 전체 사례로 최종 기준 라이브러리 재구축
→ 신규 텍스트 유사도·전술군집·유사사건 TOP3 출력
```

## 신규 텍스트 사용 방법

노트북의 `NEW_TEXTS`에 텍스트를 입력하고 해당 셀을 다시 실행합니다.

```python
NEW_TEXTS = [
    "검찰 수사 중이니 누구에게도 말하지 말고 지정 계좌로 송금하세요",
    "두 번째로 확인할 문장",
]
```

출력 항목은 다음과 같습니다.

- 문구유사도
- 전술유사도
- 군집유사도
- 종합유사도
- 전술군집ID
- 유사도 판정
- 가장 유사한 기존 사건 TOP3

## 해석 시 주의

- 정상 금융상담은 사용하지 않습니다.
- 낮은 유사도는 정상 확정이 아니라 기존 패턴과 다르거나 정보가 부족하다는 뜻입니다.
- 새로운 유형의 보이스피싱도 낮은 점수를 받을 수 있으므로 추가 검토 대상으로 처리합니다.
- 현재 임계값은 보이스피싱 내부 점수 분위수입니다.
- 최종 정상·의심 임계값과 오탐률은 정상 및 외부 데이터로 별도 검증해야 합니다.
