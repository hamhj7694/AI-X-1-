# 3단계 머신러닝 분석·학습·평가 실행 가이드

## 목적

1단계에서 만든 ML용 데이터테이블을 이용해 가설별 EDA를 수행하고, 여러 머신러닝 알고리즘을 비교한 뒤 시나리오별 최종 모델을 선정합니다.

## 실행 파일

```text
03_ml_training_evaluation.ipynb
```

노트북의 모든 셀을 위에서부터 순서대로 실행합니다.

## 입력 위치

```text
내 드라이브/보이스피싱_분석/구축 데이터셋_v3/
├─ 01_standard_tables/
└─ 02_ml_tables/
   ├─ fraud_detection_ml.parquet
   ├─ fraud_type_ml.parquet
   ├─ segment_detection_ml.parquet
   └─ case_clustering_ml.parquet
```

1단계가 먼저 정상 완료되어야 합니다. 정상 금융상담의 `TRAIN`·`VALIDATION` 구분도 보존되어야 합니다.

## 처리 순서

```text
가설·시나리오 정의
→ 중복·결측·텍스트 전처리
→ 한글 컬럼 확인용 CSV 저장
→ EDA
→ 원본 파일 단위 학습·검증·테스트 분리
→ TF-IDF 기반 여러 모델 비교
→ 검증 점수로 최종 모델 선정
→ 최종 테스트 1회
→ 결과·모델·보고서 저장
```

같은 원본 통화의 발화·사건·구간이 학습과 테스트에 나뉘지 않도록 `file_id` 또는 `group_id` 단위로 분리합니다.

## 비교하는 시나리오

| 시나리오 | 후보 모델 | 주요 지표 |
|---|---|---|
| 정상상담 vs 보이스피싱 | Dummy, Logistic Regression, Linear SVM, SGD, Complement Naive Bayes | 보이스피싱 Recall, F1, PR-AUC |
| 보이스피싱 유형 | Logistic Regression, Linear SVM, SGD, Naive Bayes | Macro F1, 혼동행렬 |
| 전체·부분 구간 탐지 | 위 텍스트 분류 모델 | 구간별 Recall, F1, PR-AUC |
| 유사 사건 군집 | K-means, MiniBatch K-means, 계층적 군집 | Silhouette, 시드 안정성 |

최종 테스트 데이터는 모델 선정에 사용하지 않습니다. 검증 데이터에서 비교한 뒤 선택된 모델을 `TRAIN+DEV`로 다시 학습하고, `TEST`에서 한 번만 평가합니다.

## 주요 결과 위치

```text
내 드라이브/보이스피싱_분석/머신러닝_분석결과_v3/
├─ 00_한글확인용/       # 사람이 읽는 한글 컬럼 CSV
├─ 01_EDA/              # 분포표·그래프
├─ 02_데이터분리/       # TRAIN·DEV·TEST 분리 결과
├─ 03_모델/             # 선정된 joblib 모델
├─ 04_예측결과/         # 최종 테스트 예측
└─ 05_보고서/           # 모델 비교·지표·한계 보고서
```

금액 원본은 `원` 단위로 보존하고, 분석용 `금액_만원`은 원 단위를 10,000으로 나눈 파생값입니다.

## 해석상 주의

- 정상상담과 보이스피싱은 출처가 달라 문체·전사 형식 차이를 학습했을 가능성이 있습니다.
- 따라서 점수는 우선 두 자료 코퍼스의 구분 성능이며, 실서비스 일반화 성능으로 해석하지 않습니다.
- 사칭 대상·요구 행동·심리전략은 규칙 기반 `SILVER` 라벨이므로 확정 정답으로 표현하지 않습니다.
- 실제 피해 여부 라벨이 없으므로 실제 피해 확률을 예측하지 않고 대화상 위험 단계만 분석합니다.
- 군집 결과는 유사 사건 후보를 찾는 비지도 결과이며 정답 유형 분류가 아닙니다.
