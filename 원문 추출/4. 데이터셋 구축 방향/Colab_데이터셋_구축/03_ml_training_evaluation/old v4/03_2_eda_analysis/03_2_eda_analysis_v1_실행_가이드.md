# 03-2 EDA 전용 Colab 실행 가이드

## Summary

`구축 데이터셋_v3`를 이용해 모델 학습 전에 데이터 품질과 주요 가설 관련 분포를 확인합니다. 결과는 `보이스피싱_분석/EDA_분석결과_v1`에 별도로 저장됩니다.

## 실행

1. `03_2_eda_analysis_v1.ipynb`를 Google Drive에 업로드합니다.
2. Colab으로 열고 **런타임 → 모두 실행**을 누릅니다.
3. 마지막에 `03-2 EDA 정상 완료`가 출력되는지 확인합니다.

## 주요 결과

- 데이터 품질·결측·중복 표
- 정상상담과 보이스피싱의 건수·길이·출처 비교
- 상대적으로 자주 등장하는 단어와 2-gram
- 사기유형 × 사칭기관·요구행동·심리전략
- 심리전략 동시출현·상관관계
- 금액 방향·용도·만원 단위 분포와 충돌 검토표
- 전체·앞·중간·뒤 구간 분포
- 사건 길이·발화 수·최초 위험행동 시점
- 자동 EDA 요약 보고서

이 노트북은 EDA 전용이며 모델 학습·최종 성능평가는 `03_ml_training_evaluation_v4.ipynb`에서 진행합니다.
