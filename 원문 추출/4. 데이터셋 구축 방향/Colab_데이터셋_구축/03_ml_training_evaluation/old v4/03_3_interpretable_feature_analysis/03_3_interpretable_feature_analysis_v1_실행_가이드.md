# 03-3 해석형 특징 기반 분석 실행 가이드

## 목적

텍스트 길이와 출처 대신 금전요구·개인정보요구·강압·긴급성·위협·비밀유지 등 해석 가능한 특징으로 정상상담과 보이스피싱을 비교합니다.

## 실행

1. `03_3_interpretable_feature_analysis_v1.ipynb`를 Google Drive에 올립니다.
2. Colab에서 열고 **런타임 → 모두 실행**을 누릅니다.
3. 마지막의 `03-3 정상 완료` 문구를 확인합니다.

입력은 `보이스피싱_분석/구축 데이터셋_v3`, 출력은 `보이스피싱_분석/해석형_특징분석결과_v1`입니다.

## 생성 결과

- 정상·사기에 동일한 규칙을 적용한 해석형 특징 데이터
- 특징별 출현 밀도·존재율·통계검정
- Dummy·Logistic·Linear SVM·Random Forest·Extra Trees 비교
- 최종 예측, 혼동행렬, 변수 중요도
- K-means 정상·사기 혼합 군집
- K-means 보이스피싱 내부 전술 군집
- 자동 요약 보고서와 실행 manifest

K-means는 정답 분류가 아니라 유사 패턴을 묶는 비지도학습입니다. 군집 생성 후 실제 라벨과의 대응과 특징 프로필을 해석합니다.
