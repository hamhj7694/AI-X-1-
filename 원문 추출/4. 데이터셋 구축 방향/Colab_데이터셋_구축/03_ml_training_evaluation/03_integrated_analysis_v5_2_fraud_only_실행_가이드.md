# V5-2 보이스피싱 단독 분석 실행 가이드

## Summary

정상 금융상담을 사용하지 않고 보이스피싱 사례 내부의 유형·사칭기관·요구행동·심리전략·금액·유사 전술을 분석합니다.

## 실행 방법

1. `03_integrated_analysis_v5_2_fraud_only.ipynb`를 Google Drive에 업로드합니다.
2. `보이스피싱_분석/구축 데이터셋_v4`가 있는지 확인합니다.
3. Colab에서 노트북을 열고 `런타임 → 모두 실행`을 선택합니다.
4. 마지막 셀에서 `V5-2 보이스피싱 단독 분석 정상 완료`를 확인합니다.

## 분석 흐름

```text
보이스피싱 데이터만 불러오기
→ 사건·발화 품질 및 유형별 EDA
→ 사건 단위 사칭기관 신뢰등급 분석
→ 요구행동·심리전략·금액 분석
→ 대출사기형 vs 수사기관사칭형 지도학습
→ 행동·심리 특징 기반 전술 K-means
→ 텍스트 기반 유사 사건 K-means
→ 결과·모델·보고서 저장
```

## 생성 결과

```text
내 드라이브/보이스피싱_분석/머신러닝_분석결과_v5_2_보이스피싱단독
├─ 01_분석표
├─ 02_그래프
├─ 03_데이터분리
├─ 04_모델
├─ 05_예측군집결과
└─ 06_보고서
```

## 해석 시 주의

- 지도학습은 대출사기형과 수사기관사칭형을 분류합니다.
- K-means 군집은 정답 분류가 아니라 유사한 전술·문구를 묶는 탐색 결과입니다.
- 사칭·행동·심리·금액은 자동 추출한 `SILVER` 라벨입니다.
- 금액은 실제 피해액이 아니며 실제 피해 여부 예측도 수행하지 않습니다.
- 정상상담을 사용하지 않으므로 정상/사기 탐지 모델로 사용할 수 없습니다.
