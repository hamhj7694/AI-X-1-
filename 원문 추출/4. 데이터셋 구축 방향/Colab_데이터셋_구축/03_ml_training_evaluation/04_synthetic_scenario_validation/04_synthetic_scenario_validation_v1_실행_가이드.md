# 가상 시나리오 검증 실행 가이드

## Summary

기존 `fraud_detection_best_model.joblib`을 재학습하지 않고 고정한 상태에서 72개의 가상 시나리오를 입력하여 오탐과 미탐을 확인합니다.

## 실행 전 조건

먼저 정상상담 vs 보이스피싱 학습 Colab을 완료하여 다음 모델이 Google Drive에 저장되어 있어야 합니다.

```text
fraud_detection_best_model.joblib
```

통합 v5의 기본 모델 위치를 우선 탐색하며, 다른 폴더에 있으면 `보이스피싱_분석` 아래에서 같은 이름의 최신 모델을 찾습니다.

## 실행 방법

1. `04_synthetic_scenario_validation_v1.ipynb`를 Drive에 업로드합니다.
2. Colab에서 열고 `런타임 → 모두 실행`을 선택합니다.
3. 마지막 셀에서 `가상 시나리오 검증 정상 완료`를 확인합니다.

## 시나리오 구성

| 구분 | 건수 | 확인 목적 |
|---|---:|---|
| 명확한 보이스피싱 | 16 | 기본 탐지 성능 |
| 은밀한 보이스피싱 | 16 | 위험 단어가 적을 때의 미탐 |
| 위험 금융용어 정상상담 | 16 | 계좌·송금 등으로 인한 오탐 |
| 일반 정상대화 | 16 | 학습 범위 밖 대화의 오탐 |
| 판단유보 | 8 | 짧거나 모호한 문장의 점수 |

정량평가는 판단유보를 제외한 64개로 계산합니다.

## 주요 결과

- 전체 Accuracy·Precision·Recall·F1
- 보이스피싱 미탐률
- 정상상담 오탐률
- 시나리오 그룹별 보이스피싱 점수
- 은밀한 보이스피싱 미탐 사례
- 위험 금융용어 정상상담 오탐 사례
- 문장 길이와 점수 관계

## 주의

- 가상 시나리오 결과는 실제 외부 데이터 일반화 성능이 아닙니다.
- 실제 음성의 ASR 오류·말 끊김·잡음·지역어를 충분히 반영하지 못합니다.
- 같은 시나리오로 모델을 계속 수정하면 평가 자료에 과적합될 수 있으므로 시나리오 버전을 고정해야 합니다.
