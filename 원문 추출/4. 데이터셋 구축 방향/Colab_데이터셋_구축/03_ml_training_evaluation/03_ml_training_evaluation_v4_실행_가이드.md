# 3단계 v4 Colab 실행 가이드

## Summary

`구축 데이터셋_v3`를 입력으로 사용하며, 결과는 `머신러닝_분석결과_v4`에 새로 저장됩니다. 기존 v3 노트북과 결과는 덮어쓰지 않습니다.

## 실행 방법

1. `03_ml_training_evaluation_v4.ipynb`를 Google Drive에 업로드합니다.
2. Colab으로 열고 **런타임 → 모두 실행**을 누릅니다.
3. 경로가 다르면 설정 셀의 `PROJECT_ROOT`만 수정합니다.

기본 경로는 다음과 같습니다.

```python
PROJECT_ROOT = Path('/content/drive/MyDrive') / '보이스피싱_분석'
DATASET_ROOT = PROJECT_ROOT / '구축 데이터셋_v3'
OUTPUT_ROOT = PROJECT_ROOT / '머신러닝_분석결과_v4'
```

## v4에서 추가된 분석

- 정상상담과 보이스피싱의 텍스트 길이 차이 확인
- 학습 표본 `1:3`과 `1:1` 비교
- 긴 텍스트를 보이스피싱 중앙값 길이에 맞춘 보정 실험
- 금액 방향·금액 용도·만원 단위 분포 확인
- 최종 테스트를 모델 선정 후 한 번만 실행

## 완료 확인

마지막 셀에서 다음 문구가 출력되면 정상 완료입니다.

```text
3단계 v4 정상 완료: /content/drive/MyDrive/보이스피싱_분석/머신러닝_분석결과_v4
```

결과 폴더에는 한글 확인용 데이터, EDA, 분리 ID, 모델 4개, 예측 결과, 지표와 보고서가 생성됩니다.
