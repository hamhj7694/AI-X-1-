# 검수 채점표 입력 가이드

`보이스피싱_검수_정량평가_Colab.ipynb`의 3번 셀을 실행하면 Google Drive의
`보이스피싱_분석/검수 및 보고서/검수_채점표.xlsx`가 생성됩니다.

## 발화검수

- 자동값 열은 수정하지 않습니다.
- `검수상태`: 해당 행 입력을 마치면 `완료`
- `정답_텍스트`: 음성을 그대로 듣고 정확한 대사 입력
- `정답_화자ID`: 사건별로 `PERSON_01`, `PERSON_02`처럼 일관되게 입력
- `정답_역할`: `OFFENDER`, `VICTIM`, `THIRD_PARTY`, `UNSURE`, `EXCLUDE`
- `음성변조`: `TRUE`, `FALSE`, `UNSURE`
- `검수메모`: 잡음, 중첩발화, 잘린 음성 등 기록

## 사건검수

- 자동 사건 하나마다 실제 시작·종료 시간을 초 단위로 입력합니다.
- 자동 경계가 맞아도 값을 복사해 사람이 확인한 정답으로 확정합니다.
- `경계판정`: `CORRECT`, `ADJUSTED`, `MERGE`, `SPLIT`, `UNSURE`
- 자동 사건 여러 개가 실제 한 사건이면 `MERGE`, 한 자동 사건에 실제 사건이 여러 개면
  `SPLIT`으로 표시하고 메모에 올바른 구조를 적습니다.

## DER 정밀구간

정식 DER이 필요할 때만 사용합니다. 화자가 바뀌는 모든 지점의 시작·종료 시각과
정답 화자 ID를 입력해야 합니다. 기존 자동 결과에는 pyannote 원시 구간이 없으므로,
현재 노트북의 기본 보고서는 정식 DER 대신 발화 시간 가중 화자 일치율을 제공합니다.

## 검수 원칙

- 판단하기 어려운 항목은 억지로 확정하지 않고 `UNSURE`를 사용합니다.
- 학습에 부적합한 무음, 음악, 손상 음성은 `EXCLUDE`를 사용합니다.
- 피해자가 변조됐을 것이라는 선입견으로 역할을 지정하지 않습니다.
- 한 사건 안에서 여러 범인이 등장하면 서로 다른 정답 화자 ID를 사용하되 역할은 모두
  `OFFENDER`로 지정할 수 있습니다.
- 개인정보를 보고서 본문이나 메모에 불필요하게 복사하지 않습니다.
