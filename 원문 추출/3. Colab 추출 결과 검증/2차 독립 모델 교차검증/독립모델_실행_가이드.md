# 독립 모델 교차검증 실행 가이드

## 목적

기존 1차 결과를 다른 계열의 모델로 재평가하고, 사람이 확인할 발화를 300~500개로
줄입니다. 모델 간 일치는 정답 정확도가 아니며, 최종 정확도는 사람이 확인한 축소
표본에서 계산합니다.

## 모델

- 2차 ASR: `facebook/mms-1b-all` 한국어 어댑터
- 2차 화자: `speechbrain/spkrec-ecapa-voxceleb` + 군집화
- 2차 역할: `MoritzLaurer/mDeBERTa-v3-base-mnli-xnli`

MMS 라이선스는 CC BY-NC 4.0입니다. 비상업 연구·검증에는 사용할 수 있지만 상업적
이용은 별도 검토가 필요합니다.

## 준비

Drive에 다음이 있어야 합니다.

```text
내 드라이브/보이스피싱_분석/
├─ 원본 영상 및 음원/
├─ 분석 결과/
└─ 검수 및 보고서/
   └─ 검수_채점표.xlsx
```

## 실행

1. 노트북을 Google Drive에 업로드하고 Colab으로 엽니다.
2. 런타임 유형을 GPU로 설정합니다.
3. 위에서부터 셀을 순서대로 실행합니다.
4. MMS와 ECAPA 결과는 실행 즉시 JSONL로 저장됩니다. 세션이 끊기면 같은 셀을 다시
   실행하면 완료 항목을 건너뜁니다.
5. `사람검수_300_500개.xlsx`가 생성되면 원본을 듣고 정답 열만 입력합니다.
6. 마지막 보고서 셀을 다시 실행합니다.

## 산출물

```text
내 드라이브/보이스피싱_분석/독립 모델 교차검증/
├─ mms_asr.jsonl
├─ ecapa_speakers.jsonl
├─ nli_roles.jsonl
├─ 50개_독립모델_교차검증.xlsx
├─ 사람검수_300_500개.xlsx
├─ 교차검증_요약.json
└─ 독립모델_교차검증_보고서.md
```

2차 전사는 기존 발화 시작·종료 구간을 사용하므로 ASR 모델은 독립적이지만 발화
세그멘테이션은 완전히 독립적이지 않습니다. 화자 일치율도 정식 DER이 아닙니다.
