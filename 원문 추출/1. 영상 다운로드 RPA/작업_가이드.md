# 보이스피싱 영상 텍스트 추출 작업 가이드

## 작업 상태

- 현재 상태: 금융감독원 공개 자료 다운로드 매크로 준비 완료, 영상 투입 대기
- 사용자가 영상 업로드 완료를 알리기 전에는 전사 작업을 시작하지 않는다.
- 입력 폴더: `원본 영상 및 음원/`
- 다운로드 도구: `download_fss_media.py`
- 사용법: `다운로드_사용법.md`
- 로컬 전사 도구: `transcribe_cases.py`
- 전사 스키마: `전사_데이터_스키마.md`

## 작업 목표

보이스피싱 사례 MP4 영상 약 300개에서 음성을 일괄 추출하고, 한국어 대화 내용을 검색·분석 가능한 텍스트 자료로 만든다.

## 기본 원칙

1. 원본 영상은 수정·이동·삭제하지 않는다.
2. 개인정보가 포함될 수 있으므로 가능한 한 로컬 환경에서 처리한다.
3. 파일별 처리 성공 여부와 오류를 기록해 중단 후에도 이어서 실행할 수 있게 한다.
4. 먼저 대표 영상 3~5개로 시험 전사를 수행하고 품질을 확인한 뒤 전체 작업을 진행한다.
5. 음성이 불명확한 부분은 임의로 확정하지 않고 `[불명확]`으로 표시한다.
6. 화자 구분은 신뢰할 수 있을 때만 적용하며, 실제 인물을 추정하거나 단정하지 않는다.

## 영상 투입 후 사전 점검

- MP4 및 기타 영상·음원 파일의 개수와 총용량 확인
- 파일별 재생시간, 오디오 트랙 유무, 코덱 확인
- 중복 파일 및 손상 파일 확인
- 사용 가능한 CPU, GPU, 저장공간과 전사 도구 확인
- 예상 처리시간 및 필요한 추가 저장공간 산정

점검 결과는 사용자에게 먼저 보고한다. 외부 API 사용이나 유료 서비스 이용이 필요할 경우 반드시 사전에 사용자 승인을 받는다.

## 권장 처리 절차

1. 입력 파일 목록과 고유 식별값을 생성한다.
2. 오디오를 전사용 형식으로 변환한다.
3. 시험 영상 3~5개를 한국어로 전사한다.
4. 사용자와 결과 형식 및 정확도를 확인한다.
5. 전체 파일을 일괄 전사한다.
6. 실패 파일만 재처리한다.
7. 파일 수와 산출물 수를 대조하고 표본 검수한다.
8. 처리 결과와 오류 목록을 사용자에게 보고한다.

## 기본 산출물 구조

별도 요청이 없으면 다음 구조를 사용한다.

```text
원본 영상 및 음원/          # 사용자 원본, 변경 금지
추출 결과/
  txt/                     # 영상별 전체 대화문
  srt/                     # 영상별 타임스탬프 자막
  json/                    # 구간, 시간, 텍스트 등 구조화 결과
  통합_전사_목록.csv        # 파일명, 상태, 길이, 전사문 경로, 오류
  처리_로그.txt
```

사용자가 Excel 통합본, 화면 자막 OCR, 화자 분리, 사건 유형 분류 또는 개인정보 마스킹을 요청하면 이를 추가한다.

## 기본 표기 규칙

- 파일 인코딩: UTF-8
- 원본 파일명 보존
- 시간 표기: `HH:MM:SS`
- 들리지 않는 말: `[불명확]`
- 음악·벨소리 등 의미 있는 비언어 음향: `[벨소리]`, `[음악]`처럼 표기
- 개인정보 마스킹을 적용할 경우 원문과 마스킹본을 구분해 저장

## 완료 기준

- 모든 입력 파일이 성공, 무음, 손상 또는 실패 중 하나의 상태로 기록됨
- 성공 파일마다 요청된 텍스트 산출물이 존재함
- 입력 파일 수와 처리 목록의 파일 수가 일치함
- 시험 결과 및 전체 작업의 표본 검수가 완료됨
- 원본 파일이 변경되지 않았음을 확인함

## 다음 행동

사용자가 영상 투입 완료를 알리면 우선 읽기 전용 점검을 수행하고, 결과를 보고한 다음 시험 전사 단계로 진행한다.
