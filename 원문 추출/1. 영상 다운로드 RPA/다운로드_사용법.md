# 금융감독원 보이스피싱 자료 일괄 다운로드

대상은 금융감독원 보이스피싱 체험관의 다음 공개 게시판입니다.

- 바로 이 목소리
- 그놈 목소리 > 대출사기형
- 그놈 목소리 > 수사기관 사칭형(검찰, 경찰 등)

## 실행

PowerShell에서 현재 폴더를 연 뒤 다음 명령을 실행합니다.

```powershell
python .\download_fss_media.py
```

파일은 `원본 영상 및 음원` 아래의 분류별 폴더에 저장되고, 진행 결과는
`원본 영상 및 음원\다운로드_목록.csv`에 계속 기록됩니다.

먼저 첫 페이지만 링크를 점검하려면 다음처럼 실행합니다.

```powershell
python .\download_fss_media.py --dry-run --max-pages 1
```

## 동작 원칙

- 게시판 마지막 페이지까지 자동 순회합니다.
- 기존에 받은 정상 파일은 다시 받지 않습니다.
- 다운로드 중 끊긴 파일은 `.part` 확장자로 남으며 다음 실행에서 다시 받습니다.
- 서버 부하를 줄이기 위해 기본적으로 요청 사이에 0.6초 대기합니다.
- MP3와 MP4만 저장합니다.
- 로그인, 보안장치 우회 또는 비공개 자료 접근은 수행하지 않습니다.

요청 간격은 `--delay 1.0`, 출력 위치는 `--output "폴더명"`처럼 변경할 수 있습니다.
