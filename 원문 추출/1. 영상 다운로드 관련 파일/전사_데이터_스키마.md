# 보이스피싱 전사·분류 데이터 스키마

## 분석 단위

파일 하나를 사건 하나로 간주하지 않는다. 긴 무음과 새로운 통화 도입부를 이용해
`case_001`, `case_002` 형식의 사건 후보로 나누며, 자동 경계는 검수 대상으로 남긴다.

## 화자와 역할

- `speaker_id`: 음성 특성으로 분리한 익명 화자(`SPEAKER_00` 등)
- `role`: 확정된 경우에만 `OFFENDER`, `VICTIM`을 부여
- `role_confidence`: 내용 기반 역할 판정 신뢰도
- `voice_modified`: 변조 여부. 자동으로 단정하지 않고 최초에는 빈 값으로 둔다.

화자분리와 역할판정은 서로 다른 값이다. 한 사건에 범인이 여러 명이거나 제3자가
등장할 수 있으므로 확신이 부족한 발화에는 역할 라벨을 부여하지 않고 검수 대상으로 격리한다.

## 산출물

각 원본 파일별로 다음 파일을 생성한다.

- `cases.json`: 사건, 화자, 발화, 모델 메타데이터를 보존하는 기준 데이터
- `turns.csv`: ML 및 통계 분석용 발화 단위 표
- `검수필요.csv`: 화자·역할·사건 경계가 불확실해 학습에서 제외한 발화
- `review.txt`: 사람이 듣고 고치기 쉬운 검수용 스크립트

원문 전사(`text_verbatim`)는 후처리로 덮어쓰지 않는다. 맞춤법 정제문, 개인정보
마스킹문, 형태소 분석 결과는 추후 별도 필드나 별도 데이터셋으로 생성한다.

## 품질 원칙

- 사건 경계, 역할 또는 변조 여부가 불확실하면 `needs_review`로 표시한다.
- 음성 변조는 피해자 역할의 근거로 사용하지 않는다.
- `UNKNOWN`을 학습용 역할 라벨로 사용하지 않는다.
- 역할 신뢰도 0.6 미만과 화자 미분리 발화는 `turns.csv`에 넣지 않는다.
- 표본 검수로 기준을 확정하기 전에는 전체 자동 결과를 확정 라벨로 취급하지 않는다.
